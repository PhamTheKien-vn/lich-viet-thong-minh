# 🗓️ Lịch Việt - Trợ Lý Thông Minh (Smart Vietnamese Calendar)

Ứng dụng lịch vạn niên hiện đại, nhẹ nhàng và riêng tư dành cho người Việt. 

## ✨ Tính năng nổi bật
- **Xem lịch Âm - Dương:** Tra cứu ngày tháng, can chi, giờ hoàng đạo chính xác.
- **Ngày lễ tự động:** Hiển thị tất cả các ngày lễ lớn trong năm (Tết Nguyên Đán, Giỗ Tổ, Quốc Khánh...).
- **Lời nhắc đa năng:** - Lưu ghi chú theo lịch Dương hoặc lịch Âm.
  - Chế độ nhắc lại hàng năm (phù hợp cho ngày giỗ, sinh nhật).
- **Quản lý thông minh:** Tìm kiếm lời nhắc nhanh chóng qua từ khóa.
- **Dữ liệu an toàn:** - Lưu trữ trực tiếp trên thiết bị (LocalStorage), đảm bảo quyền riêng tư.
  - Hỗ trợ **Sao lưu** và **Khôi phục** qua file `.json`.
- **Trải nghiệm App:** Hỗ trợ cài đặt trực tiếp vào màn hình chính điện thoại (PWA).

## 🚀 Hướng dẫn cài đặt lên điện thoại
1. Truy cập vào link GitHub Pages của bạn bằng trình duyệt (Safari trên iPhone hoặc Chrome trên Android).
2. Chọn **Chia sẻ** (iOS) hoặc **Cài đặt/3 chấm** (Android).
3. Nhấn **"Thêm vào màn hình chính"** (Add to Home Screen).

## 🛠️ Công nghệ sử dụng
- HTML5, CSS3, JavaScript (Vanilla JS).
- Thư viện `lunar-javascript` để tính toán âm lịch.
